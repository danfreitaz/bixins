# Checklist do piloto fechado 1.0

- [x] Nove espécies e 17 objetos ilustrados; imagens carregadas no navegador.
- [x] Construção, inventário, expansão, objetivos, loja, exploração, coleção e diário integrados.
- [x] Encontros reais, afinidade, amizade e conflitos leves sem dano físico.
- [x] Reprodução valida idade, espécie, A/B, saúde, necessidades, afinidade, parentesco, capacidade, estoque e cooldown.
- [x] Preparar não gera ovo instantâneo; caminhos e aconchego são necessários.
- [x] Ovo/filhote preservam genoma, traços e progenitores; transferência preserva linhagem.
- [x] Concorrência no Neon: um preparo, um ovo, um débito, um nascimento; isolamento entre propriedades.
- [x] Sem concessão de saldo ou alteração de relógio por endpoint de produção.
- [x] Incubação regular confere prazo de 90 minutos e recusa antecipada; teste de conclusão usa fixture isolada.
- [x] Ciclo dia/noite e chuva leve cosméticos, sem perda por ausência.
- [x] Som opcional, movimento reduzido e bateria; preferências persistem.
- [x] Diálogos, seletores, Escape, foco, erros e 404 revisados.
- [x] Desktop e larguras de 360, 390 e 768 pixels sem rolagem horizontal; sem erros JavaScript.
- [x] Sessão, origem, validação de corpo, idempotência, limite de requisições e cabeçalhos revisados.
- [x] Segredos e credenciais de QA ignorados pelo Git; snapshot público não expõe sementes futuras.
- [x] Economia anterior revalidada no Neon após otimização do extrato.
- [x] 100 colônias por 14 dias virtuais, sem saldo negativo ou morte/perda irreversível.
- [x] Checagem de orçamento somente por leitura e procedimento de operação documentados.
- [x] Estado anterior da segunda conta fictícia restaurado após o E2E.
